# AlphaPEA Terminal 🚀

Un terminal financier moderne et interactif dédié à l'analyse comparative des ETF éligibles au PEA (WPEA, CW8, ESE, PAASI, MEUD). 

## Fonctionnalités principales

- **Comparateur multi-ETF** : Vue d'ensemble des frais (TER), encours, prix de parts et type de réplication (synthétique/physique).
- **Simulateur DCA & Intérêts Composés** : Visualisation graphique dynamique (via Chart.js) de la progression de votre épargne mensuelle.
- **Calculateur d'Arbitrage Fiscal** : Évaluez l'impact d'une vente de CW8 en plus-value pour basculer vers un ETF aux frais réduits (WPEA).
- **FAQ Interactive** : Réponses claires sur le fonctionnement des contrats de swap, la fiscalité du PEA et l'optimisation des versements.
- **Design Responsive & Dark/Light Mode** : Interface de terminal financier soignée inspirée des outils institutionnels.

## Déploiement sur GitHub Pages

1. Créez un nouveau dépôt sur GitHub (ex: `alpha-pea-terminal`).
2. Ajoutez le fichier `index.html` et ce `README.md` à la racine.
3. Allez dans les **Settings** de votre dépôt > **Pages**.
4. Sous **Build and deployment**, sélectionnez **GitHub Actions** ou pointez sur la branche `main` / dossier `/root`.
5. Votre site est en ligne !
